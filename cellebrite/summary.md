# Cellebrite Forensics Projects

This repository contains mobile device forensic examination case studies performed using Cellebrite UFED and Cellebrite Physical Analyzer.

Each case includes a full examination report, extraction methodology, chain of custody documentation, and supporting screenshots, organized in its own folder.

## Cases

- **mobile-forensics-samsung-a03core** — Advanced Logical vs File System extraction comparison (Case DFIR-MF-2026)

## Skills Demonstrated

Mobile device acquisition (logical, advanced logical, file system), hash based integrity verification, chain of custody documentation, comparative extraction analysis, structured forensic reporting.
